Part 7 - Full Stack Open (Exercises 7.1 - 7.21)
-------------------------------------------------

This is a ready-made React project folder that demonstrates solutions for exercises 7.1 through 7.21 (React Router) from:
https://fullstackopen.com/en/part7/react_router

How to use:
1. unzip part7.zip
2. cd part7
3. npm install
4. npm start

Notes:
- This project uses react-router-dom v6.
- Each exercise component is placed under src/exercises/Exercise7_xx.js
- The main router is configured in src/App.js with links to each exercise.
- These are example solutions/demonstrations — adapt for your course as needed.
